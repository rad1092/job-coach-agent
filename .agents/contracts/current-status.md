## 자동 업데이트 방향

- 구현이 끝난 뒤 상태가 바뀌면 이 문서를 먼저 갱신한다.
- 아래 항목이 바뀌면 반드시 수정한다.
  - 현재 단계
  - 완료된 것
  - 바로 다음 작업
  - 뒤로 미룬 것
  - 검증 상태
- 규칙:
  - 기능을 구현하고 테스트까지 끝났으면 `완료된 것`으로 올린다.
  - 다음 우선순위가 바뀌면 `바로 다음 작업`을 수정한다.
  - 보류 결정이 나면 `뒤로 미룬 것`에 추가한다.
  - 실키 검증이 끝나면 `검증 상태`를 갱신한다.
