# 사용자 흐름

## 1. 목표 설정

- 사용자가 희망 산업, 직군, 직무를 입력한다
- 필요하면 지역, 경력 수준, 선호 조건을 함께 입력한다

## 2. 탐색과 후보 정리

- 관련 공고와 공개 정보를 읽는다
- 관련 기업 후보와 공고 후보를 정리한다

## 3. 지원 준비 요약

- 공고 핵심 요구사항
- 준비 포인트
- 부족한 역량과 필요한 자료
- 다음에 해야 할 준비 항목

## 4. 문서 작성

- 자소서 초안 방향
- 수정 포인트
- 경험 연결 포인트

## 5. 면접 준비

- 예상 질문
- 답변 구조
- 현재 단계에 맞는 준비 미션

## 6. 일정과 피드백 반영

- 마감일과 준비 항목 정리
- 사용자 피드백을 다음 추천과 준비에 반영
