# 산업·직군·직무 입력 구조

## 필수 입력

- `industry`: 산업, 공유 taxonomy에서 선택
- `job_family`: 직군, 공유 taxonomy에서 선택

## 조건부 입력

- `job_role`: 직군 하위 직무 선택
- `job_role`: `미정` 또는 `직접 입력` 경로 허용

## 선택 입력

- `experience_level`: `신입`, `경력무관`, `경력`
- `preferences`: 구조화된 선호 태그와 짧은 자유 메모를 직렬화한 문자열
- `user_background`: 학력, 프로젝트, 경력, 자격증, 보유 기술
- `notes`: 탐색 시 참고할 메모

## 입력 처리 원칙

- 사용자가 먼저 산업과 직군을 정한다
- 직무는 하위 선택으로 좁히되, 미정 상태를 허용한다
- 기업은 초기 입력이 아니라 탐색 결과에서 좁혀진다
- 산업·직군은 탐색 쿼리의 기본 축이 된다
- 직무가 있으면 role-specific 쿼리를 추가하고, 없으면 산업·직군 기준으로 넓게 탐색한다
- 사용자 배경과 메모는 이후 공고 분석, 문서 작성, 면접 준비 전 단계에 공통으로 반영된다

### 산업

- `IT/소프트웨어`
- `금융`
- `이커머스/리테일`
- `플랫폼/서비스`
- `콘텐츠/미디어`
- `헬스케어/바이오`
- `제조/하드웨어`
- `교육`
- `모빌리티/물류`
- `공공/비영리`
- `기타`

### 직군

- `개발`
- `데이터/AI`
- `제품/기획`
- `디자인`
- `마케팅`
- `영업/사업개발`
- `운영/프로젝트관리`
- `HR/리크루팅`
- `재무/회계`
- `고객지원/CS`

### 선호 조건 태그

- `근무형태`: `원격`, `하이브리드`, `상주`
- `고용형태`: `정규직`, `계약직`, `인턴`
- `지역`: `수도권`, `비수도권`, `해외`
- `기업규모`: `스타트업`, `성장기업`, `중견·대기업`
