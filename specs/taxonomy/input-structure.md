# 산업·직군·직무 입력 구조

## 필수 입력

- `industry`: 산업
- `job_family`: 직군
- `job_role`: 직무

## 선택 입력

- `experience_level`: 신입, 인턴, 주니어 등
- `location_preference`: 지역 선호
- `work_preference`: 근무 형태, 기업 규모, 기타 선호
- `user_background`: 학력, 프로젝트, 경력, 자격증, 보유 기술

## 입력 처리 원칙

- 사용자가 먼저 산업·직군·직무를 정한다
- 기업은 초기 입력이 아니라 탐색 결과에서 좁혀진다
- 직무 문맥은 이후 공고 분석, 문서 작성, 면접 준비 전 단계에 공통으로 반영된다

## 후속 활용

- 공고 탐색 기준
- 기업 후보 분류 기준
- `지원 준비 요약서` 문맥
- 자소서 수정 방향
- 예상 면접 질문 생성
