# 런타임 규칙 초안

## 기본 입력

- 산업
- 직군
- 직무 또는 직무 미정 상태
- 사용자 배경
- 선택한 공고 또는 탐색 대상

## 기본 흐름

1. 산업과 직군을 필수로 받고, 직무는 하위 선택 또는 미정 상태로 받는다
2. 관련 공고와 공개 정보를 정리한다
3. 관련 기업 후보와 공고 후보를 만든다
4. `지원 준비 요약서`를 생성한다
5. 필요하면 자소서, 면접, 일정 산출물로 이어간다

## 도구 사용 원칙

- 공개 웹은 공고와 기업 정보 보강에만 사용한다
- 최신성은 보강 수준으로만 다루고 완전성을 약속하지 않는다
- 산출물은 항상 사용자 산업·직군 문맥을 기본으로 하고, 직무가 있으면 세부 문맥을 추가 반영한다

## 출력 원칙

- 점수보다 근거와 준비 포인트를 우선한다
- 장황한 설명보다 바로 쓸 수 있는 요약과 체크리스트를 우선한다
- 같은 입력에서도 제품 방향이 흔들리지 않도록 확정 용어를 유지한다
